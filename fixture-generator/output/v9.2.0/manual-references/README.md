# Manual Reference Fixtures

These are manually created reference fixtures for features that are not exposed by the Kibana LensConfigBuilder API (used by the fixture generator).

## Why Manual Fixtures?

The Kibana LensConfigBuilder API (`@kbn/lens-embeddable-utils`) doesn't expose certain visualization state properties:
- `curveType` - Curve interpolation for line charts
- `endValue` - End value handling for line/area charts
- `fillOpacity` - Fill opacity for area charts
- `minBarHeight` - Minimum bar height for bar charts
- `showCurrentTimeMarker` - Show current time marker in time series

These properties exist in the Kibana visualization state JSON format and are supported by Kibana, but the LensConfigBuilder API doesn't provide methods to set them.

## Files

- `panel_0_line_with_fitting.json` - Line chart with fitting function, emphasize fitting, end value, and curve type
- `panel_1_area_with_fill_opacity.json` - Area chart with fill opacity
- `panel_2_bar_with_min_height.json` - Bar chart with minimum bar height
- `panel_3_line_with_time_markers.json` - Line chart with time markers (showCurrentTimeMarker, hideEndzones)

## How These Were Created

These fixtures were generated by:
1. Creating YAML configurations with all the new features
2. Compiling with our kb-dashboard compiler
3. Extracting the visualization state from the compiled output

## Validation

These fixtures validate that our compiler produces the correct JSON structure for properties that can't be generated via the LensConfigBuilder API.
